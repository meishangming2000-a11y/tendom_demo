## Known Limits

- The lift demo uses a raised demo floor/table plane to keep the object inside the current arm workspace.
- The grasp is scripted position control, not learned policy behavior.
- The arm motion is not optimized for naturalness.
- Collision proxy v2 is simplified and tuned for smoke checks.
- Clean STL meshes remain visual-only.
- No tendon routing is modeled.
- No RL/BC/training has been run in this stage.
- The current result is not stable arbitrary-object grasping.
